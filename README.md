# Silai Diary – Tailor Manager

Professional Gujarati tailor-management PWA styled to match the supplied Silai Diary design.

## Flow
1. Intro / Splash screen
2. Login / Create account / Forgot password
3. Home dashboard
4. Customers & measurements
5. Normal sewing records
6. ⭐ Special Daily Sewing — separate date-wise record
7. Daily, monthly and yearly reports
8. WhatsApp monthly/daily reports
9. Cloud sync through Supabase

## GitHub Pages
Upload all files to the repository root (do not upload only the ZIP). Then enable Settings → Pages → Deploy from branch → `main` → `/ (root)`.

The Supabase publishable key is safe for browser use; database access is protected by Row Level Security.
