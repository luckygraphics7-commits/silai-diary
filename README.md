# Silai Diary – Tailor Manager

Professional Gujarati tailor PWA.

Features:
- Email login, signup and forgot password
- Cloud sync with Supabase
- Customer name, mobile and village
- Shirt/Jubba and Pant/Lengha measurements
- Daily sewing entries with date and customer
- Separate daily report
- Monthly and yearly totals
- Monthly WhatsApp report
- Daily WhatsApp report
- PWA install support

## GitHub Pages
Upload the files in this folder directly to the repository root (not inside a ZIP/folder), then enable:
Settings → Pages → Deploy from a branch → main → / (root) → Save.
